# basedline

Yet another GNU Readline alternative. Designed to be used with [Based Engine](https://gitlab.com/trexxet/basedengine).

### Features
* Supports Microslop's cmd & conpty
* Non-blocking input
* Small & compact code base

### Feature goals
* POSIX support
* wchar support
* Compatibility with GNU Readline keybinds
* Basic history
* Support for external autocompleter (or maybe would move here the one I made for Based Engine)
